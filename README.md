## 🌐 About XDOL

XDOL Digital Dollar (XDOL) is a multichain digital asset with contract references on Ethereum (ERC-20), BNB Smart Chain (BEP-20), TRON (TRC-20), and Robinhood Chain. The project focuses on liquidity, transparency, and long-term usability within decentralized finance (DeFi).

The project is designed to support a structured and sustainable digital asset ecosystem, prioritizing real utility, accessibility, and scalable infrastructure.

## 🔍 Transparency

On-chain transactions, holders, and contract-level supply must be checked on the corresponding network explorer using the exact contract address above. An explorer's per-network total is not a consolidated multichain circulating-supply figure.

The existing [supply.json](supply.json) is a dated Ethereum snapshot, and [market-data.json](market-data.json) describes an Ethereum market. Neither file is a current consolidated multichain total. [token.json](token.json) retains the Ethereum contract metadata for compatibility. Code verification on an explorer does not establish a completed independent audit.
